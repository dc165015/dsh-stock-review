# 个股深度股评

把一段研究员的写作流程固化成可复用的技能：给代码，出报告（Markdown + 单文件 HTML）。

## 能力

| 环节 | 内容 |
| --- | --- |
| 代码核实 | 东财行情接口确认代码↔名称，F10 确认全称与行业 |
| 行情 | 现价、涨跌幅、总市值、自由流通市值、TTM PE、年内涨幅 |
| 舆情 | 韭研公社 / 雪球 / 同花顺 / 东财 / 淘股吧，近 14 天多空观点 |
| 涨停 | 近 60 日最近一次涨停的概念、行业/公司原因、封板形态 |
| 业务结构 | 最新年报主营构成：占比、营收、毛利率、产品与下游 |
| 财报 | 最新年报 + 最新季报：营收、归母净利、同比、毛利率、负债率、经营现金流 |
| 研报 | 近 60 日覆盖家数、评级分布、目标价、共识与分歧 |
| 风险 | 基于正文逻辑的 2 条精简风险 |
| 报告 | 十段式 Markdown + 深色 HTML（折叠卡片 / sticky 导航 / ECharts） |

## 使用

1. 对话里发代码：`股评 600519`。
2. 技能会自动执行「核实 → 采集 → 写 JSON → 生成 HTML → 输出全文」。
3. HTML 默认生成在当前工作目录：`<代码>_股评_<日期>.html`，可直接打开或分享。

## 生成的 HTML 包含

- 顶部 sticky 导航，锚点跳转 + 当前章节高亮
- 5 个行情数据卡（现价 / 总市值 / 自由流通市值 / TTM PE / 年内涨幅）
- 可折叠章节卡片（hover 微动效）
- 图表：各平台多空观点对比、营收结构环形图、评级分布、营收/净利/毛利率趋势
- 数据来源清单与免责声明
- 移动端自适应、打印样式

## 字段与生成器

数据 JSON 的完整字段见 `SKILL.md`「第 3 步」。手动重渲染：

```bash
python scripts/build_report.py scripts/sample_data.json -o demo.html
```

`sample_data.json` 中的数字部分来自公开接口（2026-11 实测），标注 `"demo": true` 时页面顶部会显示“示例数据”提示条。

## 限制

- 依赖公开数据接口；接口变更时会退回搜索，缺失数据写“—”并注明，不编造。
- 股吧内容受登录/反爬限制，可能只有标题与摘要。
- 仅供研究，不构成投资建议。

# 个股深度股评（dsh-stock-review）

输入一个股票代码，得到一份完整的个股深度股评：十段式 Markdown 全文 + 自包含的深色财经主题 HTML 报告。

## 安装

```bash
dsh plugin --profile web add dsh-stock-review
```

或在 DSH 里：**Plugins → 添加插件**，选择本目录。装完无需额外配置。

## 触发方式

在对话里直接给代码，或使用技能名：

```
股评 600519
用 stock-review 分析一下 300750
```

## 它做什么

1. **核实代码**：东方财富行情接口确认「代码 → 名称」，F10 公司资料确认「名称 → 全称」，对不上就停下来问你。
2. **采集真实数据**：现价/市值/PE/年内涨幅、主营构成、年报+季报财务指标、近 60 日券商研报、近两周股吧舆情、近 60 日涨停、近半年并购重组。
3. **写十段式股评**：核心结论（含预期差）→ 舆情 → 涨停 → 并购 → 业务结构 → 核心优势 → 财报点评 → 券商研报 → 风险 → 来源。
4. **生成 HTML**：`scripts/build_report.py` 把数据 JSON 渲染成单文件网页——深蓝 `#0b1628` 底色、金色 `#f5c063` 强调、红涨绿跌、卡片可折叠、顶部 sticky 导航、ECharts 图表（营收结构、评级分布、多空对比、财务趋势）。

## 数据口径

- 金额：亿元；百分比：直接写数值（86.8 = 86.8%）
- 舆情：近 14 天；涨停、研报：近 60 日；并购：近半年
- 窗口内没有内容 → 整节自动隐藏（HTML 与 Markdown 章节序号同步重排）

## 限制

- 依赖公开接口，不保证永远可用；接口失效时技能会退回搜索并标注“未获取”，不会编造。
- 舆情站点（韭研公社、雪球）有登录/反爬，部分内容只能拿到标题摘要。
- 输出是研究信息，不构成投资建议。

## 结构

```

scripts/build_report.py                      HTML 生成器（Python 标准库，无第三方依赖）
scripts/sample_data.json                     渲染示例（demo 数据）
references/data-sources.md                   接口地址、字段换算、解析陷阱
docs/DETAIL.md                               插件详情页
```
